# front 床実装

基点: 34c0090、作業ブランチ: feat/front-map-art。元の slum 作業ツリーは変更せず、/tmp/front-floor-work の sparse 作業コピーで実装。

## 変更
- 128×80、偏位8px、頂点共有と面分割を保持。古代石3色、暗い目地、上辺の60%までの面取り、段付き側面、5%の平行刻線、開始地点±70pxを避けた段。
- 目地の共有頂点列を結ぶ長さ256〜384px程度の脈を2〜4本。静的な芯と、弧長・波長120px・周期6.5秒・基底α0.04の青白い光を分離。ハローαは0.35倍。網目・枝・発光継ぎ目は作らない。
- 脈の始点に接する面1枚を無発光の結晶板へ置換。画面を横にずらしても露頭が重ならない間隔で配置。
- drawCachedFloor / floorCacheTrim / floorHazKey は区画共用可能。256px、変換スケール0.25刻み、zone/seed/hazard/ART_VER/scaleとチャンク座標をキーにする。ワールド寸法も含める。初回可視分を生成、その後はG.tごとに2チャンクまで。未生成・過大スケールは直接描画。Map順のLRU、24枚・6MiB。ART_CACHEと合計16MiBを両方向から制限する。
- hazardキーには既存hazKeyに加え型・座標・半径を含め、静的形状の変更にも対応する。rift/noiseの判定楕円+16pxを静穏域とし、明細線は保守的に外側で抑制。結晶板はhazard外接矩形と重なる場合も生成しない。
- 脈光は静穏域の外側12pxで減衰し、線幅・分割線分を考慮してさらに7pxの余裕を取る。teleKと48px以内の半減を適用。
- ART_VER=2。FRONT_ART_VER=2・配置コード・OFMのA=null経路は保持。

## サンプル
- sample.png / sample.svg: 床のみ、t=0/1.625/3.25秒と2倍表示。実際のCanvas描画命令をSVG化してlibrsvg/Cairoでラスタライズした証跡。ブラウザーのスクリーンショットではない。
- sample.html: 単独で開ける動作サンプル。時間進行、2倍、rift/noise、グレースケール、停止。
- index.html: 完成したゲームHTML。適用先は game/index.html（このファイル単体には元ゲームの画像・音声は同梱しない）。

## 設計上の選択
- 脈は共有する行境界の折れ線に限定し、任意の始点から伸びる網目は作らない。任意枝は省略（仕様は1本まで）。露頭は始点のみ。2〜4本の数はマップ高に応じ、基準画面の密度制約を優先する。
- 静穏域は安全側に広めに抑制する。判定楕円+16pxの内部へ高輝度を漏らさないため。
- 共通キャッシュの接続対象は今回frontのみ。他区画の描画とOFMは変更対象外。

## 引き継ぎ

元リポジトリの.gitは読み取り専用のため、pushは行わず適用パッチを納品する。
