# border 床の実装

基点: feat/border-map-art / 508e6fd。作業コピー: /tmp/border-floor-work。
元の作業ツリーは feat/front-map-art のため、その HTML は上書きしていません。完成版は index.html、適用は border-floor.patch を 508e6fd のブランチへ git am してください。main へはマージしていません。

## 構成
- seed の y_lane から 62+64k の最寄り行と次行を通路に指定。既存スラブ・識別刻印・1% の継ぎ目を保持。
- 外側は32px段、48/64/80pxの石灰岩。指定3色、目地、受光、25%層理。3px金物と16×24px花崗岩帯、96pxごとの刻み。通路交差部にも金物。
- 石英は固定seedオフセットの間隔 ceil(W/3) × ceil(H/2) の格子で、任意の基準画面に最大6点。hazard・通路・石帯内は省略。
- electric矩形とnoise楕円の判定形状＋16px（描画幅に1px余裕）で受光・層理・石英・継ぎ目を抑止。面と目地は残す。
- 床は完全静止。OFMルーティングとdeco生成・配置・キーは変更なし。

## キャッシュ
frontの補助と同名・同方式の256pxチャンク、0.25刻みの変換スケール、LRU24個、6MiB、オブジェクトと共有16MiB。階層初回は可視チャンク生成、その後1フレーム最大2個、未生成は直接描画。electricの寸法もhazardキーに含める。
frontのキー式とART_VERは維持し、borderだけ独立のBORDER_FLOOR_VER=2を使用。既存decoのART_VER参照を変えないための意図的な版管理。BG_ART.border.floorへ材質を追加。

ブラウザ/実機の操作、hazard重畳スクリーンショット、5区画灰色比較、CPU p95 2ms/フレーム増10%の測定は未実施。利用できるブラウザ実行環境がなく、PNGはオフライン描画です。連絡係長での実機確認が必要です。
