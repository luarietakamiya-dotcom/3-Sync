# 3-Sync ノイズダイブ　画像生成の指示書（GPT用）

画像生成AI（ChatGPT など）に素材を描いてもらうための指示書です。

**大原則：1回の生成で描くのは1枚の絵（1コマ・1アイコン）だけ。** 何コマも1枚に詰め込むと、コマが減ったり、等身が崩れたり、描き込みが雑になります。アニメは1コマずつ別々に作り、Claude が後で並べてつなげます。

---

## 0. 使い方（人間向け）

1. 新しいチャットを開き、**「1. 共通プロンプト」をまるごと貼る**（チャットの最初に1回だけ）。
2. 参考画像を添付する。敵を描くときは既存の敵画像4枚（`pink_slime.png` `high_jump_slime.png` `drum_mimic.png` `sign_mimic.png`）、顔・カットイン・タイトルは3人のキャラシート。
3. **設定画を作る**：各キャラの「設定画」のプロンプトを貼り、気に入るまで作り直す。
4. **コマを1枚ずつ作る**：OKの設定画を添付して、「コマ1」のプロンプトだけを貼る。できたら、設定画とコマ1を添付して「コマ2」を貼る……と、**1回に1コマ**ずつ進める。
5. できた画像を「2. 受け取りチェック」で確認。ダメなら「3. 直してもらうときの文」で直させる。
6. 1体ぶん（または数枚）そろったら、そのまま Claude に貼る。**切り出し・縮小・足元合わせ・コマの並べ替え・ゲームへの組み込みは Claude がやる。**

> 敵1体につき6コマのチャットは長くなるので、**敵ごとに新しいチャット**を開くと崩れにくい（共通プロンプトと参考画像はその都度貼る）。

## 1. 共通プロンプト（チャットの最初に貼る）

```
あなたは2Dゲームのスプライト職人です。これから「3-Sync ノイズダイブ」というサイバーパンク×オカルトの見下ろしアクションゲームの素材を描いてもらいます。以下は全依頼に共通のルールで、絶対に守ってください。

【1回に描くのは1枚の絵だけ】
- 1回の返答で描くのは、依頼された1コマ（1体・1ポーズ）または1個のアイコンだけ。
- 複数のコマ・複数のポーズ・複数のアイコンを1枚に並べない。コマ割り・グリッド・連続写真のような構図にしない。
- その1枚に集中して、輪郭・陰影・ハイライト・細部まで丁寧に描き込む。急いで描いたような省略をしない。

【画風】
- 添付した既存の敵画像と同じタッチのドット絵風イラスト。
- 太めの暗い輪郭線（ほぼ黒の濃紫）、ツヤのあるハイライト、ネオンのピンク(#ff4fa8)とシアン(#3fe0ff)の差し色、ところどころに小さなグリッチ（デジタルノイズの破片）。
- 光は左上から、影は右下。
- 見下ろし斜め（3/4ビュー）の正面寄り。どのコマも同じ向き（左右反転しない）。
- かわいさ7：不気味さ3。目つきは悪いが愛嬌がある。

【キャンバス（キャラ・敵のとき）】
- 画像は1024×1024ピクセルの正方形。背景は完全な透過。透過できない場合だけ単色 #00FF00 で塗りつぶす（被写体に緑が多いときは #FF00FF）。
- キャラは1体だけ、左右の中央に置く。
- 足元（地面に接している所）は、画像の下端から128px上の水平線にそろえる。浮いている敵は、依頼に書いた高さに浮かせる。
- キャラの高さは画像の約60%（ボスは約75%）。毎回同じ大きさで描く。
- 床・地面・影・背景・文字・番号・枠線は描かない（影はゲーム側で描く）。

【一貫性（最重要）】
- 添付の設定画（と、すでに描いたコマ）が正解。そのデザインを1ドットも変えない。
- 頭身・頭の大きさ・胴の長さ・手足の長さと太さ・目の位置と形・配色・模様・装飾の数は、設定画とまったく同じにする。
- 全体の大きさと位置は、設定画・前のコマと同じ（±5%以内）。指定がない限り、大きくも小さくもしない。
- 変えてよいのは、そのコマの説明で指定したポーズ・表情・部位だけ。

【出す前の自己チェック】描いたら次を確認し、1つでも外れていたら描き直してから出すこと。
(1) 絵は1枚で、キャラは1体・1ポーズだけ
(2) 背景・床・影・文字・枠線がない
(3) 頭身・大きさ・配色が設定画と同じ
(4) 足元の高さが指定どおり
(5) 説明どおりのポーズになっている
```

## 2. 受け取りチェック（人間が確認する）

- [ ] 1枚に1体・1ポーズだけ（コマが並んでいない）
- [ ] 設定画と同じデザイン（色・模様・目の形・装飾の数）
- [ ] 頭身が変わっていない（頭だけ大きい、体が縮んだ、などがない）
- [ ] 大きさが前のコマとそろっている
- [ ] 足元の高さがそろっている（浮遊の指定があるコマは除く）
- [ ] 文字・番号・枠線・床・影・背景がない
- [ ] 向きがそろっている（左右反転していない）
- [ ] 描き込みが雑になっていない（輪郭がぼやける、ハイライトが消える、などがない）

## 3. 直してもらうときの文（コピペ用）

問題の画像と設定画を添付して、当てはまるものを貼る。

```
頭身が変わっています（頭が大きく、体が短い）。添付の設定画と同じ頭身・同じ大きさで描き直してください。ポーズはそのままでかまいません。
```

```
前のコマより大きく（小さく）なっています。キャラの高さを前のコマと同じ（画像の約60%）にして描き直してください。ポーズは変えないでください。
```

```
設定画とデザインが違います（色・模様・目の形・装飾の数）。添付の設定画とまったく同じデザインに戻して描き直してください。
```

```
複数のコマ（ポーズ）が1枚に並んでいます。指定した1コマだけを、1枚に1体で描き直してください。
```

```
文字（または床・影・背景・枠線）が入っています。それらを全部消して、背景を完全な透過にしてください。キャラは変えないでください。
```

```
前のコマとほとんど同じポーズです。このコマは「（ここに本来のポーズの説明）」なので、その違いがはっきり分かるように描き直してください。
```

```
描き込みが雑になっています。輪郭線の太さ、ツヤのハイライト、陰影を、設定画と同じ丁寧さで描き直してください。
```

## 4. ボス（5体・各6コマ）

ボスは画面で大きく表示されるので、細部まで描き込んでOK。コマの割り当ては全ボス共通：

| コマ | 用途 |
| --- | --- |
| 1・2 | 移動（2枚を交互に再生） |
| 3 | 技の溜め（予備動作） |
| 4 | 技を放つ瞬間 |
| 5 | 咆哮（HPが減って本気になる瞬間） |
| 6 | ひるみ（大ダメージを受けた瞬間） |

## 12. Claude に渡すときのメモ

- 画像はそのまま貼ってOK（ファイル名は変えなくてよい）。どの絵か一言そえる（例：「5-2 ケーブルハウンドのコマ1〜6」）。
- コマは Claude が足元をそろえ、64×64（ボスは128×128）に縮小し、ゲームの再生順につなげる。大きさや位置が少しずれていても直せる。
- 1体ぶんだけでも、1枚だけでも、届いたらすぐ組み込める。少しずつで大丈夫。
